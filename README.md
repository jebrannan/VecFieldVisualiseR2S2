A MATLAB Live Editor toolkit for visualizing vector fields on R² and S² manifolds with color-coded magnitude(pop pop) mapping.
This is a very rudimentary visualiser for vector fields on either the 2 dimensional Real plane or the 2-sphere in 3 dimensions.
I did this in order to help quickly visualise vector fields while taking a class on manifolds in college
It takes in simple enough inputs, just the coefficents of the coordinate derivatives.
It uses colour to represent magnitude as opposed to size in order to keep space and let it be more readable
